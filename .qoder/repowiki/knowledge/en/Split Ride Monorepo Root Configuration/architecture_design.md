This leaf is a pure-configuration root with no application source code; all runtime logic lives under `src/` (aliased via `@/*` → `./src/*`). Key boundaries: `next.config.ts` declares an App Router project with Turbopack enabled, whitelists Firebase as server externals, and restricts Next image optimization to `placehold.co`, `api.dicebear.com`, and S3 buckets. `components.json` drives shadcn/ui generation using the radix-luma style, RSC mode, Hugeicons, and three custom registries (`@mapcn`, `@shark`, `@spectrumui`) whose aliases mirror tsconfig's `@/*`. `postcss.config.mjs` wires Tailwind v4 through `@tailwindcss/postcss`. `biome.json` configures Biome v2 with recommended Next/React domains, import organization assist, and git-aware VCS integration. `tsconfig.json` enforces strict TypeScript with bundler module resolution and the Next plugin. Runtime scripts are thin wrappers around `next dev/build/start`; formatting/linting use `biome format --write` and `biome check`. A Windows helper script `check_changes.ps1` and a `Split DB.zip` seed are included at the root.
